# 🍱 Food Donation App

A mobile application built in **Java** using **Firebase** as the backend, designed to connect food donors with NGOs and individuals in need. This Android app helps reduce food waste and support social causes by enabling seamless food donation and collection.

## 📱 Features

- 🔐 User Authentication (Firebase Auth)
- 🎁 Post Food Donations with details (images, quantity, location)
- 📍 Real-Time Location Tracking via Google Maps API
- 🧾 Donation Status Tracking
- 🔔 Push Notifications for donation updates
- 👥 Separate Modules for Donors and Receivers (NGOs)

## 🛠️ Tech Stack

| Technology | Usage |
|-----------|--------|
| Java | Core Android app development |
| XML | UI Layout Design |
| Firebase Authentication | User login/signup |
| Firebase Realtime Database / Firestore | Data storage & retrieval |
| Firebase Storage | Store food images |
| Google Maps API | Location tracking and navigation |
| Android Studio | Development IDE |

🔒 Security & Privacy

User data is stored securely in Firebase.
Authentication tokens are managed by Firebase Auth.
Real-time access rules are enforced using Firebase security rules.
